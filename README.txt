BLACK LABEL BARBER CLUB — SITE DEMONSTRATIVO
Projeto estático responsivo para GitHub + Vercel.

ARQUIVOS
index.html — conteúdo e estrutura
style.css — identidade visual e responsividade
script.js — menu mobile, animações e formulário

PUBLICAR PELO CELULAR
1. Extraia o ZIP.
2. Envie index.html, style.css e script.js para a raiz do repositório GitHub.
3. Faça o commit.
4. Importe o repositório na Vercel. Framework: Other; Build command vazio; Output directory: ./

PERSONALIZAÇÃO ANTES DE ENTREGAR AO CLIENTE
- Troque o nome BLACK LABEL e o Instagram pelo nome real.
- Atualize preços, endereço, horário e serviços (os valores atuais são ilustrativos).
- Em script.js, substitua 5585991359742 pelo WhatsApp da barbearia (55 + DDD + número).
- As imagens são carregadas do Unsplash por internet; não há pasta de fotos local.
- O formulário envia uma solicitação pelo WhatsApp. Não confirma agenda automaticamente nem processa pagamentos.
